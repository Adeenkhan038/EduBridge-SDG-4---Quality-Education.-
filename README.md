# EduBridge-SDG-4---Quality-Education.-
Principles of Software Engineering Group Project - SDG-aligned prototype

Project Overview

ITS 610204 Principles of Software Engineering | Semester February 2026
Agile Software Solution for Sustainable Development Goal 4: Quality Education

EduBridge addresses the critical lack of STEM tutoring access for rural Malaysian high-school students by providing a lightweight, mobile-first web platform that connects them with university student volunteers. This no-code prototype demonstrates complete user flows for students, tutors, and school coordinators using Agile/Scrum methodology over 4 weeks.
Problem Statement

 -Rural students lack personalized STEM tutoring due to distance, cost, and connectivity constraints
 -University students want to volunteer but lack a structured platform
 -Schools need oversight and reporting for external tutoring programs

SDG 4 Impact
"Ensure inclusive and equitable quality education and promote lifelong learning opportunities for all" - By lowering barriers to STEM support, EduBridge narrows the urban-rural education gap.

    🎨 Prototype Features (Live Demo)

Student Journey:

 Landing Page → Explains value propositio
 Account Creation → Name, school, STEM subjects needed
 Browse Tutors → Filter by Physics/Add Maths, view profiles
 Book Session → Select time slot, confirm request
 My Sessions → Upcoming/past sessions list
 Rate Session → 1-5 stars + quick comment

Tutor Journey:

 Create Profile → University, subjects offered, availability
 Manage Availability → Set weekly time slots
 View Bookings → Accepted sessions with student details
