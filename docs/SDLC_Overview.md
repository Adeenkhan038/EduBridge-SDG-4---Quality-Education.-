# SDLC Overview – EduBridge

## 1. Planning & Requirements
- Created Product Vision, Personas, Stakeholder Analysis
- Gathered user stories in Product Backlog

## 2. Analysis
- Defined Use Case Diagram with actors and interactions
- Analyzed stakeholder needs and constraints

## 3. Design
- Created wireframes, ER diagram, user flows
- Designed high-fidelity prototype screens

## 4. Implementation / Prototyping
- Built clickable prototype in Figma/Canva
- Exported screens to GitHub /design and /prototype

## 5. Testing & Evaluation
- Wrote Test Plan and Test Cases
- Conducted user testing with 3 students
- Documented feedback and improvements

## 6. Reflection
- Lessons learned about Agile, teamwork, tools
- Documented in final report
